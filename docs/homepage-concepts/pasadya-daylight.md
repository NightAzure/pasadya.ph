# Pasadya Daylight Homepage Direction

Pasadya Daylight remains an earlier homepage exploration centered on qualified
local search, practical comparison, and trip planning. It is now a reference
concept rather than Pasadya's live homepage direction.

## Status

- **Current role:** archived comparison direction
- **Live homepage direction:** [Sunlit Field Guide](sunlit-field-guide.md)
- **Concept route:** `/homepage-concepts/pasadya-daylight`

## What Daylight still contributes

1. Search-first discipline
2. Honest listing-card rules
3. Clear planning and transport hierarchy
4. Practical trust language for booking decisions

## Why Sunlit Field Guide replaced it

1. The live homepage needed a stronger sense of place and a more memorable visual identity.
2. The editorial split hero makes route context feel integrated instead of appended.
3. The navigation model is cleaner: explore, plan, guides, and routes are easier to scan.
4. The category rail and local-lens sections create better first-step choices before dense comparison begins.

## Migration note

When Daylight guidance conflicts with Sunlit Field Guide guidance, treat
Sunlit Field Guide as the source of truth for the live homepage, shared public
navigation, and current design-system direction.
